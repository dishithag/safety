# Synthetic Trend Demo Data

Everything in this directory is isolated demonstration data for a possible
future trend-analysis capability. It is not production history and is never
written to MinIO or read by the Go services.

`portfolio-week.json` contains seven daily snapshots for eight curated CIDs.
The final snapshot is copied from the synthetic repository fixtures. The six
earlier snapshots are deterministic, plausible demo history generated by
`demo-ui/scripts/generate-trend-fixture.mjs`.

The UI derives score bands, portfolio medians, recurring and zero-compliance
control counts, CID movement, daily platform movement, device volume, and
resolved/introduced/still-zero transitions from this one fixture. Those
calculations are deterministic; the browser does not ask an LLM to calculate
metrics.

`seed-reports/` contains isolated copies of the eight synthetic source fixtures
used to generate the history. The browser does not load these larger source
files; they exist to make the demo provenance inspectable.

Regenerate from the repository root fixtures with:

```shell
cd demo-ui
npm run generate:trends
```

When the UI is copied outside the backend repository, the checked-in generated
fixture remains self-contained. Set `SOURCE_REPORTS_DIR` only if regeneration
from another fixture location is required.
